# PLM-technology

# Система бронирования ресурсов

Проект для управления бронированием переговорных комнат и других ресурсов.

## Цель проекта
Предоставить удобный интерфейс для создания, просмотра и отмены броней.

## Команда
- **Соня** (TL) — координация, ревью, настройка процессов
- **Тимур** (Analytics) — схема БД, алгоритмы, требования
- **Ксюша** (Design) — макеты, UI/UX, HTML-прототипы
- **Егор** (Backend) — API, БД, атомарные транзакции
- **Никита** (Frontend) — вёрстка, интеграция с API
- **Вика** (QA) — тестирование, тест-планы
- **Роман** (PO) — приёмка результата
