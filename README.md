# Система бронирования ресурсов (PLM-technology)

Проект для управления бронированием переговорных комнат и других ресурсов.

## Цель
Удобный интерфейс для создания, просмотра, переноса и отмены броней.

## Команда
- **Соня** (TL) — координация, ревью, процессы
- **Тимур** (Analytics) — схема БД, статусы, требования
- **Ксюша** (Design) — макеты, UI/UX, HTML-прототип
- **Егор** (Backend) — API, БД, транзакции
- **Никита** (Frontend) — вёрстка, интеграция с API
- **Вика** (QA) — тест-план, кейсы, отчёт
- **Роман** (PO) — приёмка

## Стек
- **Backend:** Python, FastAPI, uvicorn, psycopg2 (API `0.7.0`)
- **Frontend:** HTML, CSS, JavaScript (`docs/frontend/index.html`)
- **БД:** Embedded PostgreSQL (`pgserver`), БД `booking` (инициализация через `docs/bd/init_db.py`)
- **API:** контракт `docs/API_CONTRACT.md` **v1.2** (синхронизирован с кодом) + Swagger `http://127.0.0.1:8000/docs`
- **Процесс:** Wiki репозитория (команда, правила, запуск, flow)

## Структура

## Быстрый старт
1. Бэкенд: Wiki → «Запуск бэкенда» или `docs/bd/readme.txt` (БД поднимается через `init_db.py`, файл `*.db` в git не храним)
2. Фронт: Wiki → «Запуск фронта» или `docs/frontend/README.txt`
3. Swagger: `http://127.0.0.1:8000/docs`
