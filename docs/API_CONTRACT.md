##  Общие правила

### Формат данных
- Все запросы и ответы в формате **JSON**
- Кодировка: **UTF-8**
- Content-Type: `application/json`

### Формат времени
**Строго ISO 8601:** `YYYY-MM-DDTHH:mm:ss`

Пример: `2026-10-15T14:30:00`

### Базовый URL
```
http://localhost:8080/api/v1
```
*(порт может отличаться, уточнить у бэкенда)*

---

##Модели данных

### Resource (Ресурс / Переговорная)
```json
{
  "id": 1,
  "name": "Переговорная Альфа",
  "capacity": 8,
  "location": "3 этаж, комната 301"
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer | Уникальный идентификатор ресурса |
| `name` | string | Название ресурса |
| `capacity` | integer | Вместимость (кол-во человек) |
| `location` | string | Расположение |

---

### Booking (Бронь / Заявка)
```json
{
  "id": 42,
  "resource_id": 1,
  "resource_name": "Переговорная Альфа",
  "start_time": "2026-10-15T10:00:00",
  "end_time": "2026-10-15T11:00:00",
  "user_name": "Иван Иванов",
  "description": "Встреча с клиентом",
  "status": "CONFIRMED",
  "created_at": "2026-10-12T14:30:00"
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | integer | Уникальный идентификатор брони |
| `resource_id` | integer | ID ресурса |
| `resource_name` | string | Название ресурса (для удобства) |
| `start_time` | string | Время начала (ISO 8601) |
| `end_time` | string | Время конца (ISO 8601) |
| `user_name` | string | Имя пользователя |
| `description` | string | Описание встречи (необязательно) |
| `status` | string | Статус брони |
| `created_at` | string | Дата создания брони (ISO 8601) |

## Endpoints

### 1. Получить список ресурсов

**Метод:** `GET`  
**Путь:** `/resources`

**Ответ:** `200 OK`
```json
{
  "resources": [
    {
      "id": 1,
      "name": "Переговорная Альфа",
      "capacity": 8,
      "location": "3 этаж, комната 301"
    },
    {
      "id": 2,
      "name": "Переговорная Бета",
      "capacity": 4,
      "location": "2 этаж, комната 205"
    },
    {
      "id": 3,
      "name": "Переговорная Гамма",
      "capacity": 12,
      "location": "1 этаж, комната 101"
    }
  ]
}
```

---

### 2. Создать бронь

**Метод:** `POST`  
**Путь:** `/bookings`

**Тело запроса:**
```json
{
  "resource_id": 1,
  "start_time": "2026-10-15T10:00:00",
  "end_time": "2026-10-15T11:00:00",
  "user_name": "Иван Иванов",
  "description": "Встреча с клиентом"
}
```

**Обязательные поля:**
- `resource_id` (integer) — ID ресурса
- `start_time` (string, ISO 8601) — время начала
- `end_time` (string, ISO 8601) — время конца
- `user_name` (string) — имя пользователя

**Необязательные поля:**
- `description` (string) — описание встречи

**Валидация на клиенте (Frontend):**
- `end_time` должен быть позже `start_time`
- Время не может быть в прошлом

**Ответ:** `201 Created` (успех)
```json
{
  "id": 42,
  "resource_id": 1,
  "resource_name": "Переговорная Альфа",
  "start_time": "2026-10-15T10:00:00",
  "end_time": "2026-10-15T11:00:00",
  "user_name": "Иван Иванов",
  "description": "Встреча с клиентом",
  "status": "PENDING",
  "created_at": "2026-10-12T14:30:00"
}
```

**Ответ:** `409 Conflict` (накладка)
```json
{
  "error": "booking_conflict",
  "message": "Переговорка занята в выбранное время",
  "conflicting_booking": {
    "id": 15,
    "start_time": "2026-10-15T10:30:00",
    "end_time": "2026-10-15T11:30:00"
  }
}
```

**Ответ:** `400 Bad Request` (невалидные данные)
```json
{
  "error": "validation_error",
  "message": "Время конца должно быть позже времени начала"
}
```

**Ответ:** `404 Not Found` (ресурс не найден)
```json
{
  "error": "resource_not_found",
  "message": "Ресурс с ID 999 не существует"
}
```

---

### 3. Получить список броней

**Метод:** `GET`  
**Путь:** `/bookings`

**Query-параметры (необязательные):**
- `resource_id` (integer) — фильтр по ресурсу
- `date` (string, YYYY-MM-DD) — фильтр по дате
- `status` (string) — фильтр по статусу (PENDING, CONFIRMED, CANCELLED)

**Пример запроса:**
```
GET /bookings?resource_id=1&date=2026-10-15
```

**Ответ:** `200 OK`
```json
{
  "bookings": [
    {
      "id": 42,
      "resource_id": 1,
      "resource_name": "Переговорная Альфа",
      "start_time": "2026-10-15T10:00:00",
      "end_time": "2026-10-15T11:00:00",
      "user_name": "Иван Иванов",
      "description": "Встреча с клиентом",
      "status": "CONFIRMED"
    },
    {
      "id": 43,
      "resource_id": 1,
      "resource_name": "Переговорная Альфа",
      "start_time": "2026-10-15T14:00:00",
      "end_time": "2026-10-15T15:00:00",
      "user_name": "Мария Петрова",
      "description": "Планёрка команды",
      "status": "PENDING"
    }
  ]
}
```

---

### 4. Отменить бронь

**Метод:** `POST`  
**Путь:** `/bookings/{id}/cancel`

**Параметры пути:**
- `id` (integer) — ID брони

**Пример запроса:**
```
POST /bookings/42/cancel
```

**Ответ:** `200 OK` (успех)
```json
{
  "id": 42,
  "status": "CANCELLED",
  "message": "Бронь успешно отменена"
}
```

**Ответ:** `404 Not Found` (бронь не найдена)
```json
{
  "error": "booking_not_found",
  "message": "Бронь с ID 999 не существует"
}
```

**Ответ:** `400 Bad Request` (бронь уже отменена)
```json
{
  "error": "already_cancelled",
  "message": "Бронь уже отменена"
}
```

## Коды ошибок

| Код | Название | Описание |
|-----|----------|----------|
| `400` | Bad Request | Невалидные данные запроса |
| `404` | Not Found | Ресурс или бронь не найдены |
| `409` | Conflict | Наложение бронирований |
| `500` | Internal Server Error | Внутренняя ошибка сервера |

---

## Ключевые бизнес-правила

### Атомарность
Проверка накладок в `POST /bookings` должна быть **атомарной** (транзакции БД или блокировки).  
При одновременных запросах от двух пользователей только один проходит.

### Отменённые брони
Брони со статусом `CANCELLED` **не учитываются** при проверке накладок.  
После отмены время снова становится свободным.

### Валидация времени
- `end_time` > `start_time` (обязательно)
- Время не может быть в прошлом (рекомендуется)

## Примеры использования (cURL)

### Создание брони (успех)
```bash
curl -X POST http://localhost:8080/api/v1/bookings \
  -H "Content-Type: application/json" \
  -d '{
    "resource_id": 1,
    "start_time": "2026-10-15T10:00:00",
    "end_time": "2026-10-15T11:00:00",
    "user_name": "Иван Иванов",
    "description": "Встреча с клиентом"
  }'
```

### Получение списка броней на дату
```bash
curl "http://localhost:8080/api/v1/bookings?resource_id=1&date=2026-10-15"
```

### Отмена брони
```bash
curl -X POST http://localhost:8080/api/v1/bookings/42/cancel
```
