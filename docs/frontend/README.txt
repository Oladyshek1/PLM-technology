ИНСТРУКЦИЯ ПО ЗАПУСКУ

1. Запустить БД и бэкенд (инструкция в bd\readme.txt).
2. Открыть файл frontend/index.html.


РЕАЛИЗОВАННЫЙ ФУНКЦИОНАЛ:
1. Вход и регистрация. Сессия сохраняется в браузере, имя выводится в шапке, открывается раздел "Мои брони".
2. Сетка времени и статусы слотов (белый — свободно, красный — занято другим, синий — своя бронь, серый — прошедшее время).
3. Создание брони
4. Загрузка активных броней пользователя с характеристиками помещений (вместимость, площадь, оборудование).
5. Отмена брони.
6. Перенос брони.
