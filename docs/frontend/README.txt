ИНСТРУКЦИЯ ПО ЗАПУСКУ
1. Скачать проект из корня (PLM-technology/)
2. Запустить БД и бэкенд (инструкция в bd/readme.txt).
3. Открыть файл docs/frontend/index.html.


РЕАЛИЗОВАННЫЙ ФУНКЦИОНАЛ:
1. Вход и регистрация: сохранение сессии в браузере, имя в шапке, разделение доступа по ролям (USER — «Мои брони», ADMIN — «Брони»).
2. Главная страница: карусель помещений из БД с фото и характеристиками.
3. Сетка времени и выбор слотов: недельный календарь, скрытие занятых и прошедших слотов, выбор нескольких слотов подряд.
4. Создание брони: бронирование одного или нескольких интервалов времени.
5. Раздел «Мои брони»: фильтры по помещению и датам, автоматическое скрытие закончившихся броней (END ≤ now).
6. Отмена брони: диалог подтверждения, отмена своей брони пользователем.
7. Перенос брони: выбор новой даты в календаре и времени с автоматическим переносом.
8. Админ-панель («Брони»): фильтры по помещению, датам и поиск по заказчику, сводка часов занятости по помещениям за период, таблица всех броней с сортировкой по времени и статусами, снятие (отмена) броней администратором.
9. Информация о системе: модальное окно с версией и контактами поддержки из API.
